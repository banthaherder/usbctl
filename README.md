# usbctl

A virtual USB disk manager for macOS that creates and manages virtual disk images using `hdiutil`.

## Overview

`usbctl` allows you to create, mount, unmount, and manage virtual disk images on macOS without needing physical USB drives. Virtual disks are stored as raw disk image files in `~/.usbctl/` and can be attached/detached like real USB drives.

## Requirements

- macOS (uses `hdiutil` and `diskutil`)
- Python 3.10+

## Installation

1. Make the script executable:
   ```bash
   chmod +x usbctl.py
   ```

2. (Optional) Add it to your PATH or create a symlink:
   ```bash
   ln -s $(pwd)/usbctl.py /usr/local/bin/usbctl
   ```

## Usage

### Create a new virtual disk

```bash
usbctl create <name> <size_gb> [--fs FILESYSTEM]
```

Creates a new virtual disk with the specified name and size.

**Note:** Disk names must be 11 characters or less to ensure compatibility with FAT/ExFAT filesystems.

**Examples:**
```bash
# Create a 4GB ExFAT disk named "backup"
usbctl create backup 4

# Create a 8GB FAT32 disk
usbctl create usb8 8 --fs FAT32

# Create a 16GB APFS disk
usbctl create data 16 --fs APFS
```

**Supported filesystems:**
- `ExFAT` (default)
- `FAT32`
- `APFS`
- `HFS+` (Mac OS Extended)
- Any filesystem supported by `diskutil eraseDisk`

### List all managed disks

```bash
usbctl list
```

Shows all virtual disks in `~/.usbctl/` with their current status (attached/detached/mounted).

**Example output:**
```
managed disks in $HOME/.usbctl:
  - backup: mounted at /Volumes/BACKUP (file=$HOME/.usbctl/backup.raw, device=/dev/disk4)
  - usb8: detached (file=$HOME/.usbctl/usb8.raw)
```

### Mount a virtual disk

```bash
usbctl mount <name>
```

Attaches and mounts an existing virtual disk.

**Example:**
```bash
usbctl mount backup
```

### Unmount a virtual disk

```bash
usbctl unmount <name>
```

Detaches a virtual disk (unmounts all volumes and removes the device).

**Example:**
```bash
usbctl unmount backup
```

### Get disk information

```bash
usbctl info <name>
```

Shows detailed information about a specific virtual disk.

**Example output:**
```
disk 'backup':
  file: $HOME/.usbctl/backup.raw
  size: 4294967296 bytes
  status: attached
  device: /dev/disk4
  mount: /Volumes/BACKUP
```

### Delete a virtual disk

```bash
usbctl delete <name>
```

Permanently deletes a virtual disk file. The disk must be unmounted first.

**Example:**
```bash
usbctl unmount backup
usbctl delete backup
```

## Debug Mode

Enable debug mode to see all system commands before execution:

```bash
usbctl --debug <command>
```

## Storage Location

All virtual disk files are stored in:
```
~/.usbctl/
```

Each disk is stored as a `.raw` file (e.g., `backup.raw`).

## Common Workflows

### Create and use a virtual USB drive

```bash
# Create a 8GB drive
usbctl create myusb 8

# It's automatically mounted, copy files to /Volumes/MYUSB
cp -r ~/Documents/mypaper.pdf /Volumes/MYUSB/

# Unmount when done
usbctl unmount myusb

# Mount again later
usbctl mount myusb
```

### Clean up old virtual disks

```bash
# List all disks
usbctl list

# Unmount and delete unwanted disks
usbctl unmount oldusb
usbctl delete oldusb
```

## Troubleshooting

### Disk won't unmount
If a disk is in use, you may need to close applications accessing it first, then retry:
```bash
usbctl unmount <name>
```

### Disk shows as attached but not mounted
Check the device and mount points manually:
```bash
usbctl info <name>
diskutil list
ls /Volumes
```

### Force detach (advanced)
If `usbctl unmount` fails, you can manually detach:
```bash
hdiutil info
hdiutil detach /dev/diskX  # replace X with actual device number
```
